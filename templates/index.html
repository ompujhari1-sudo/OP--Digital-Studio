User Input

Ask a question, upload a PDF, paste an error or a code snippet.

Request Processing

Likely cause

The Python interpreter running your script cannot find a package named requests. It is usually not installed in the active environment, or you are using a different interpreter than the one you installed it in.

Steps to investigate
  • Check which interpreter runs your code, because pip may have installed to another one.
  • Install into that same interpreter so both always match.
  • If you use a virtual environment, make sure it is activated.
python -m pip --version
